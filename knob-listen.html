Knob listener (sends nothing)

This page opens the keyboard and only listens. It never sends a command or requests a report, so it can't change anything on the keyboard. It logs every report the keyboard sends on its own.

  1. Close RT75 Studio and qmk.top first; only one page can hold the keyboard.
  2. Click Start listening and pick the RT75 (or its 2.4G dongle). If the picker shows several entries for it, start again and pick each one.
  3. Turn the knob a few clicks and press it once, then click Mark and note "volume mode".
  4. Hold the knob to change mode. Watch for new lines.
  5. Turn and press it again in the new mode, then Mark it. Repeat for each mode.
  6. Click Copy log and paste it into the chat.
